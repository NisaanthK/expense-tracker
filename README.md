🎬 CinemaCalc - Actor Budget Tracker
This is a React-based Expense Tracker developed as part of a task for CinemaCalc, aimed at managing and calculating actor budgets for film projects.

1. 📌 Features
✅ Add actors with individual cost

✅ Track total expense

✅ View remaining budget

✅ Responsive and clean UI

✅ Simple budget management system tailored for production teams

2. 🚀 Live Demo
https://nisaanthk.github.io/expense-tracker/

3. 🛠️ Tech Stack
React.js (Functional Components)

HTML5, CSS3

JavaScript (ES6)

GitHub Pages (Deployment)

4. Getting Started
git clone https://github.com/NisaanthK/expense-tracker.git
cd expense-tracker
npm install
npm start


5. 🧠 Purpose
This project showcases budgeting logic in a film production scenario. It helps producers manage costs in real-time while planning actor casting.
